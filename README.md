# NIH ChestX-ray14 PyTorch Project

Deep learning project using the **NIH ChestX-ray14** dataset to build and evaluate multi-label chest X-ray classification models with PyTorch.

The project will cover:

- Dataset inspection and exploratory analysis
- Patient-level train, validation, and test splitting
- Multi-label classification
- PyTorch datasets and dataloaders
- Image preprocessing and augmentation
- Transfer learning with convolutional neural networks
- Class imbalance handling
- Model training and validation
- ROC-AUC and precision-recall evaluation
- Threshold selection
- Error analysis
- Grad-CAM explainability
- Clinical usefulness and limitations

## Data Source

The NIH ChestX-ray14 dataset contains **112,120 frontal chest X-ray images from 30,805 patients**. The dataset includes labels for 14 thoracic disease categories derived from associated radiology reports.

The dataset is publicly available through the National Institutes of Health and will be used in accordance with the dataset's attribution and usage requirements.
