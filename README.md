# VinDr-CXR PyTorch Project

Deep learning project using the VinDr-CXR chest X-ray dataset to build and evaluate medical image classification models with PyTorch.

The project will cover:

- DICOM image handling
- Dataset inspection and exploratory analysis
- PyTorch datasets and dataloaders
- Image preprocessing and augmentation
- Transfer learning with convolutional neural networks
- Model training and validation
- Classification metrics and threshold selection
- Error analysis
- Model explainability
- Clinical usefulness and limitations
